# Calculator

Open `index.html` in any modern browser by double-clicking it. Keep `index.html`, `styles.css`, and `script.js` together in this folder. No installation, build, server, or internet connection is required.

Click the buttons or use your keyboard: digits, decimal point, +, -, *, /, Enter or =, Backspace, and Escape or C to clear.

Operations run sequentially, like a basic pocket calculator: 2 + 3 × 4 = gives 20. Choose another operator before entering a number to replace the pending operator. After a result, entering a digit starts a new calculation; choosing an operator continues from that result. Division by zero displays an error; Clear or a digit starts again. Results use 12 significant digits to reduce floating-point artifacts.

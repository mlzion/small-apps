04 / Level Preview / Test

Play starts at zero and loops continuously using the level’s motion rates. Each gate uses its configured width; width edits update live. Stop resets to zero. Preview has no collisions or damage.

05 / Publish / Import

Edits stay in memory in this tab. Test Mode opens a separate tab. Publish downloads a complete JSON file; it is not live until Codex installs it and GitHub Pages deploys it. Reloading or closing this editor discards edits. The editor never writes to the repository.
